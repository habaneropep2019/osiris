# Osiris

The `qt-legacy` branch is only provided for historical reference purposes. These are **not** Osiris releases. It's also important to note that they **do not** have any bug fixes or security updates. No one provides support for them. Again, they are **only for reference purposes**. These were obtained from the Qt [archive website](https://download.qt.io/archive/qt/2/) and have not been modified other than being unpacked. Only Qt version 2 is archived here.
